# 📸 SnapExpense

**Snap a photo, track your expense. It's that simple.**

SnapExpense is a smart expense tracker that lets you capture receipts with your camera, automatically extract the data, and organize your spending — no manual entry required.

---

## ✨ Features

- 📷 **Photo-based capture** — snap receipts instantly
- 🤖 **AI data extraction** — automatic amount, date, and merchant recognition
- 📊 **Expense dashboard** — visual overview of your spending
- 🗂️ **Category management** — organize expenses by type
- 📱 **Mobile-friendly** — designed for on-the-go use

## 🚀 Getting Started

```bash
git clone https://github.com/P-create-sumo/SnapExpense.git
cd SnapExpense
npm install
```

Create a `.env.local` file:

```env
VITE_BASE44_APP_ID=your_app_id
VITE_BASE44_APP_BASE_URL=https://your-app.base44.app
```

Run locally:

```bash
npm run dev
```

## 🛠 Tech Stack

- **React 18** + Vite
- **Tailwind CSS**
- **Base44 SDK** — entities, auth, AI vision
